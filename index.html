Supabase に接続します。

接続先（初回のみ）

Supabase ダッシュボード → Settings → API に両方あります。この端末のブラウザにだけ保存されます。

ログイン

アカウントは Supabase ダッシュボードの Authentication → Users → Add user → Create new user で作ります（Auto Confirm User にチェック）。作ったら Authentication → Sign In / Providers → Email の「Allow new users to sign up」を OFF に。
押しても何も起きないときは「接続テスト」を押してください。

オフラインで使う

接続できないときの逃げ道です。入力内容はこの端末に残り、次にログインしたときにまとめて送信されます。

スマホ・PCで使う

同じファイル（または同じURL）を開いて同じアカウントでログインすれば、データは自動で同期されます。

iPhone：ファイルを「ファイル」App に保存 → Safariで開く → 共有 →「ホーム画面に追加」。
Android：Chromeで開く → メニュー →「ホーム画面に追加」。

オフラインでも入力でき、オンラインに戻ると自動送信されます。
